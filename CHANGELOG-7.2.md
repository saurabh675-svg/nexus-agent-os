# Nexus 7.2

- Added Reality Loop missions with durable checkpoints, action/evidence graphs, safe interruption recovery, approval handling, and user-feedback lessons for future runs.
- Added a Kaggle research-to-baseline starter and a Business Analyst role/recipe with evidence, downside, and validation-focused guidance.
- Expanded the default 08:30 local daily briefing with cited news across science, technology, business, and economics; reports are shown in the desktop widget.
- Corrected Doctor so the intentional remote-failover-off default is not reported as a failure.
- Added an optional Electron desktop shell that reuses the local Nexus service and stores packaged-app data in the user profile.
- Added image-capable OpenAI-compatible vision providers with explicit provider selection; Ollama remains the private local default.
- Made remote chat failover opt-in so a local request does not automatically send prompts to a hosted model.
- Added live image/tool capability metadata to OpenRouter free-model discovery.
- Added VS Code MCP setup documentation and Git ignore rules for local runtime data and secrets.
- Corrected provider notes to distinguish local inference from metered cloud services and variable free quotas.
