# Research brief

## Shape of the deliverable
1. **Answer** — 2–3 sentences, lead with the conclusion.
2. **Evidence** — bullets, each with an inline URL and the date of the source.
3. **What this means** — the implication for the user's actual situation.
4. **Unverified / conflicting** — anything single-source, stale, or contested.

## Method
- 3–6 sub-questions, one `web_search` each with different phrasing. Never reuse a query.
- `open_page` the winner; a snippet is not evidence.
- Two independent sources for any number that matters. If only one exists, label it.
- Prefer primary sources: the org's own page over an article about it.

## Refusals
- No invented URLs, dates, statistics, or quotes.
- If the web gives nothing usable, say "no reliable source found" — that is a valid answer.
